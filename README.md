# 競技プログラミング精進記録

[AtCoder](https://atcoder.jp/) を中心に、競技プログラミングで解いた問題の提出コードを記録しています。

## ディレクトリ構成

```
atcoder/
├── 2019/    AtCoderの提出コード(年ごと)
├── 2020/
├── 2021/
├── 2022/
├── 2023/
├── 2024/
├── 2025/
├── 2026/
├── codeforces/  Codeforcesの提出コード
└── tenkei90/    競プロ典型90問の解答・解説PDF
```

年ごとのフォルダの中は、`abc242a.cpp` のような命名(コンテスト名+問題番号)のファイルが直接置かれている場合と、`20210102_ABC187` のようにコンテスト日付ごとのサブフォルダに分かれている場合があります(記録していた時期によって形式が異なります)。

## 使用ライブラリ

一部のコードで [AC Library](https://github.com/atcoder/ac-library) を使用しています。
`#include <atcoder/all>` を使うファイルをコンパイルする場合は、対象フォルダ内に AC Library を配置してください。
