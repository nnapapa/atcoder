# AtCoder 精進記録

[AtCoder](https://atcoder.jp/) で解いた問題の提出コードを年ごとに記録しています。

## ディレクトリ構成

```
atcoder/
├── 2024/
├── 2025/
└── 2026/
```

各フォルダにコンテストごとの提出コードを `abc242a.cpp` のような命名(コンテスト名+問題番号)で置いています。

## 使用ライブラリ

一部のコードで [AC Library](https://github.com/atcoder/ac-library) を使用しています。
`#include <atcoder/all>` を使うファイルをコンパイルする場合は、各年フォルダ内に AC Library を配置してください。
